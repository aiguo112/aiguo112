## Research highlights

### PanoDive360 — Underwater 360° semantic segmentation
Novel underwater ERP dataset with enhanced attention for multiclass segmentation under polar distortion.

![PanoDive360 Underwater 360° Semantic Segmentation](./images/PanoDive360 Underwater 360° Semantic Segmentation.png)

### ERP-Transformer — Outdoor panoramic segmentation
SegFormer + squeeze-and-excitation channel recalibration for outdoor 360° scenes.

![ERP-Transformer Outdoor Panoramic Segmentation](./images/ERP-Transformer Outdoor Panoramic Segmentation.png)

### LatentPano — 360° scene classification
Latitude-aware spatial transform for robust indoor / outdoor / commercial ERP classification.

![LatentPano 360° Scene Classification](./images/LatentPano 360° Scene Classification.png)

### SA-RSRefSeg — Scale-aware referring remote sensing
Natural-language referring segmentation for high-resolution aerial imagery.

![SA-RSRefSeg Scale-Aware Referring Remote Sensing](./images/SA-RSRefSeg Scale-Aware Referring Remote Sensing.png)

### Detect-Then-Segment — Space target perception
Two-stage pipeline for non-cooperative satellites / spacecraft.

![Detect-Then-Segment Space Target Perception](./images/Detect-Then-Segment Space Target Perception.png)

### Text-Steered Modality Routing — SAR–optical fusion
Annotation-free SAR + optical land-cover segmentation steered by language.

![Text-Steered Modality Routing SAR-Optical Fusion](./images/Text-Steered Modality Routing SAR-Optical Fusion.png)

### Beyond Perspective — Panoramic crowd counting
Latitude-aware density maps for 360° ERP crowd counting.

![Beyond Perspective Panoramic Crowd Counting](./images/Beyond Perspective Panoramic Crowd Counting.jpg)
